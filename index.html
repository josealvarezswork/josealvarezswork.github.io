Case Studies

Two systems built on the same idea: a progression loop only works if the player can read, at any moment, what state they're in and what the system is asking of them. Characters, XP economies, streaks and fail states — designed as systems, not decorations.

The framework behind both

Emotional State Architecture

ESA is my own framework: a four-state machine where every state has a trigger, a psychological mechanism and an action it invites. It drives the characters, the reward tiers and the fail states in both case studies.

Trigger — day start, no activity

Pure potential. The day begins without pressure. An expectant posture: the character waits, it doesn't judge.
